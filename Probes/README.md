# Probes — Replication Guide

## Overview

This experiment trains probes on hidden states from the Geometric Characterization pipeline. All code is self-contained within a single notebook.

> **Note:** Update `MODEL_NAME` and the input file path inside `Probes.ipynb` before running.

---

## Pipeline Steps

### Step 1 — Prepare Input Data

This experiment reuses outputs already generated by the Geometric Characterization pipeline. Ensure the following files have been produced before proceeding:

- `Geometric_characterization/extractStates.py` — unlabeled hidden states
- `Geometric_characterization/LlmAsAJudge.py` — labeled states file

Refer to the [Geometric Characterization replication guide](#) if these have not been generated yet.

---

### Step 2 — Train Probes

Open and run `Probes.ipynb`. The notebook loads the labeled states from the Geometric Characterization experiment and trains probes across layers using the same methodology.

**Input:** Labeled states file from `Geometric_characterization/LlmAsAJudge.py`  
**Output:** `probe_results/MODEL_NAME/` *(one subdirectory per model)*

---

## File Reference

| File | Role | Output |
|---|---|---|
| `Geometric_characterization/extractStates.py` | Produces unlabeled hidden states (upstream dependency) | States file |
| `Geometric_characterization/LlmAsAJudge.py` | Labels hidden states (upstream dependency) | Labeled states file |
| `Probes.ipynb` | Trains and evaluates probes across layers | `probe_results/MODEL_NAME/` |
